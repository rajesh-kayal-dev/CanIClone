# Code of Conduct

## Our commitment

CanIClone is an individually maintained open-source project. We want participation to be respectful, constructive, and welcoming for everyone, regardless of experience, background, identity, or viewpoint.

## Expected behavior

- Be respectful and considerate in issues, discussions, and pull requests.
- Assume good intent and ask clarifying questions before making assumptions.
- Give and accept constructive technical feedback.
- Focus criticism on code, behavior, evidence, and documentation rather than personal attributes.
- Respect privacy and never share credentials, private data, or unpublished security details.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized language, deliberate disruption, and other conduct that makes participation unsafe are not acceptable. This applies in all project spaces and when representing the project publicly.

## Scope

This Code of Conduct applies to repository issues, pull requests, discussions, code reviews, and other interactions connected with CanIClone.

## Reporting

Instances of unacceptable behavior may be reported privately through the maintainer's GitHub profile: [rajesh-kayal-dev](https://github.com/rajesh-kayal-dev). Please include enough context for the maintainer to understand the situation. Do not include secrets or private user data in a public report.

## Enforcement

The maintainer may edit or remove comments, issues, pull requests, or other contributions that do not follow this Code of Conduct. Repeated or serious violations may result in temporary or permanent participation restrictions.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), using a concise structure appropriate for this project.
